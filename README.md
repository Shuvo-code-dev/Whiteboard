# Actor-Board

A fast, lightweight, **single-file** HTML5 Canvas whiteboard for freehand sketching, quick diagrams, brainstorming, and notes—with zero external dependencies or build steps.

## Features

- **Smooth Freehand Drawing:** Draw freely using a mouse, trackpad, or touch screen with responsive pointer support.
- **Color Palette & Custom Picker:** Includes quick color swatches plus a custom color picker.
- **Brush Size & Eraser:** Adjust stroke thickness (`1px` to `40px`) and switch seamlessly between pen and eraser modes.
- **Undo & Clear:** Step back with the **Undo** button or `Ctrl+Z` / `Cmd+Z`, or reset the canvas with **Clear**.
- **One-Click PNG Export:** Save your board with a clean white background as a timestamped `.png` image.
- **100% Client-Side & Private:** Runs completely in your browser with no server uploads, accounts, or tracking.

## Quick Start

1. Download `index.html`.
2. Open it directly in any modern web browser (Chrome, Firefox, Edge, Safari).
3. Start drawing and click **Save PNG** whenever you want to export your work.
